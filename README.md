## 这是什么

模型来自 B 站 **@氵六青**（UID 11272072）无偿配布的《大肥鱼！丨免费 Live2d 模型》。
这个项目做的是把她搬到**安卓**上 —— 不是打开一个 App 看她，而是她就浮在你手机屏幕上：
你切到微信她在、刷视频她在、回桌面她还在。

她平时就是待着：揣着点菜板、手里捏支笔，眼睛跟着你的手指转，你不动她她就自己换张表情走神。
你摸她头会脸红，摸个没完她是会生气的。你让 AI 干活时，她在旁边跟着进度变脸。

## 特性

**🔹 真·安卓悬浮窗，窗口正好等于她的轮廓**
她以外的地方完全不挡触摸 —— 该点点的照点、该上滑的照滑。
单指拖着她满屏跑、双指捏合改大小；拖到哪、多大、多透明，都记得住。

**🔹 跟着 Agent 的实时状态走（16 种）**
思考冒问号、翻资料戴眼镜、改文件贴猫猫贴纸、跑命令眼睛变星星、联网查资料、
派子代理、列计划、等你确认；一轮收工伸懒腰庆祝、出错流汗、被打断冒感叹号；
同一个工具反复失败会脸红挤番茄酱、连着几步顺利会双手比耶、超过 90 秒的长任务她会打瞌睡。
头顶那条状态条写的是**桥给的原话**（例如「正在执行 bash npm test …」）。
**44 张脸随你配**：哪个状态配哪张，设置里逐条改。

**🔹 眼神会跟着你**
手指在她身上滑动，眼睛和头跟着手指走；**超出你设的范围她就不看**，自己慢慢回正。范围 0–800px 可调。

**🔹 动作与表情播放的规则全都能调**
自动换表情 / 最短保持 / 换脸概率 / **换脸时顺带做个动作的概率** /
闲置动作间隔（**0 = 完全不做**）/ 两次动作最小间隔 /
**动作白名单 + 表情白名单**（逐条勾选）/ 一键「**让它安静点**」/
一行诊断随时告诉你白名单生效没有。

**🔹 45 项互动，软件外面也能开菜单**
15 张脸 + 11 件装饰 + 8 个场景 + 14 个一次性动作（外加 🎲 随机表情 / 🎲 随机动作）。
长按她、点她头顶的状态条、或拉通知栏都能开菜单，分页：表情 / 装饰 / 场景 / 动作 / 设置。

**🔹 不装插件也能联动**
插件要动 DSH 的 profile、还要重启。所以另做了一条：直接读 DSH 的会话转写
`session.v3.jsonl.zstd`，喂给同一套状态机，**不碰 DSH 任何文件**。两条可以同时留着。

**🔹 它会自己修自己**
WebView 渲染进程被系统回收时不把 App 带走，而是立刻重建，她一两秒后自己回来。

## 安装与首次授权

1. 从 [Releases](https://github.com/zovoeh830/jingjing-pet/releases) 下载 `鲸鲸桌宠.apk` 直接安装
2. 首次给她两个权限：
   - **显示在其他应用上层**（悬浮窗权限）—— 面板「悬浮窗」页里有「授权」按钮
   - **通知权限**（Android 13+）—— 不给也能跑，只是前台上层服务那条通知不显示
3. 点桌面图标，**她直接出来**（设置面板自动退到后台，不挡着她）

**自检**（确认她真的在跑）：

- 长按她 → 弹出菜单；点她头顶那句话也能开菜单；通知栏里有一条常驻通知
- 想看内部状态：手机浏览器打开 `http://127.0.0.1:8765/debug`，能看到版本、窗口几何、最近日志

## 跟 Agent 的联动

两条通道，装一个就行，也可以都装：

| 通道 | 说明 |
| --- | --- |
| **DSH 插件**（主力） | `tools/dsh-pet-bridge/`，装进 DSH profile 后自动加载 |
| **会话转写监听**（待命） | `tools/pet-watcher.js`，直接读 `session.v3.jsonl.zstd`，不碰 DSH 任何文件；插件不在时自动接手 |

状态机与气泡文案与 DSH 的 `dsh-pet-bridge` 对齐，16 个状态逐字一致。
她头顶那条状态条写的就是桥推过来的原话。

## 兼容性与适配

| 系统 | 处理 |
| --- | --- |
| Android 7–7.1 | 悬浮窗用旧的 `TYPE_PHONE` |
| Android 8+ | 改用系统强制的 `TYPE_APPLICATION_OVERLAY`，并建通知渠道 |
| Android 11+ | 「显示在其他应用上层」是独立授权页，启动前会校验 |
| Android 12+ | 启动闪屏按新 API 适配（背景与页面同色、图标正常显示）；**某些应用会主动隐藏悬浮窗** |
| Android 13+ | 运行时申请 `POST_NOTIFICATIONS`；不给也能跑 |
| Android 14 | targetSdk 32 属兼容模式，前台服务不强制声明类型，实测稳定 |

另外：**手机竖屏、手机横屏、平板**三种比例都渲染截图核对过 —— 面板内容居中、可滚动、页签吸顶、安全区留白。

## 常见问题

**她没出现 / 一会儿就不见了**
两种原因，日志里能分清：① 银行、支付、游戏、安装器这类应用声明了「隐藏悬浮窗」，
它们在前台时系统会把所有悬浮窗藏起来 —— **退出它们她就自己回来**；
② WebView 渲染进程被系统回收（内存紧张时常见），现在会自动重建，一两秒后回来。

**点桌面图标后是一个黑屏/只有背景**
正常情况下点图标是**直接出桌宠**、面板退后台。如果看到的是空面板，请确认版本 ≥ 1.12.2
（更早的版本在面板模式下没读模型清单，导致设置里的表情/动作列表是空的）。

**设置里的"状态对应的表情"下拉只有"不改变表情"**
同上，≥ 1.12.2 已修。

**面板滑不动**
面板模式下 `body` 就是滚动容器，手指可以直接滚。如果某台设备仍然滑不动，告诉我机型和版本。

**怎么彻底关掉她**
面板「悬浮窗」页 → 「关闭悬浮窗」；或者长按她 → 「✕ 关闭悬浮窗」。

## 换成你自己的 Live2D 模型

这个 App 是**外壳**：悬浮窗、互动、Agent 联动、播放规则都在前端；模型只是一堆文件 + 一份清单。
所以换成任何**你有授权**的 Live2D 模型都可以：

1. 把模型放进 `_model_src/`（至少要有 `.moc3`、贴图、动作、表情）
2. 编辑 `tools/prepare_assets.py` 里的来源路径与 `index.json` 生成部分
   （`gaze` 注视映射、`expressions` 表情清单、`motions` 动作清单、以及"哪个状态配哪张脸"都在那里定义）
3. 重新生成资源并构建：

```bash
python3 tools/prepare_assets.py
bash tools/build.sh
```

4. **记得改署名**：面板页脚、`model/index.json` 的 `credit`、README 的版权表 ——
   如果用别人的模型，请先确认许可（本项目用的是 CC BY-NC-SA 4.0，必须署名 + 非商业 + 相同方式共享）。

## 开发与自测

```bash
git clone https://github.com/zovoeh830/jingjing-pet.git
cd jingjing-pet
```

不需要 Android Studio，也**不需要 Gradle** —— 工程里带的是一套很朴素的脚本：

```bash
bash tools/build.sh          # 产物：dist/鲸鲸桌宠.apk
```

依赖 `aapt`、`javac`（JDK 8+）、`d8`（`r8.jar`）、`zipalign`、`apksigner`，以及 `python3`。

自测**不需要真机**，跑在 Playwright 的 Chromium / WebKit 上，共 200+ 条：

```bash
node tools/webtest.js      # 页面逻辑（56 条）
node tools/overlaytest.js  # 悬浮窗行为（127 条）
node tools/paneltest.js    # 面板 / 手机平板排版（35 条）
```
